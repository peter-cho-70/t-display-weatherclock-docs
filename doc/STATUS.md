# 개발 현황 (STATUS)

> 기준일: 2026-07-26 — 이 문서는 append하지 않고 매번 "현재 기준"으로 덮어써서 갱신한다. 히스토리는 DEVLOG.md에 남긴다.

## ✅ 완료

- LilyGO T-Display-S3용 Wi-Fi 시계 + 날씨 디스플레이 예제(`examples/WeatherClock`) 구현.
- TFT_eSPI 기반 320×170 가로 레이아웃, [Open-Meteo](https://open-meteo.com/) API(API 키 불필요, 무료)로 위치·날씨 조회.
- WiFiManager 캡티브 포털 기반 설정 UI: 최초 부팅 시 AP 모드로 전환되어 폰/PC 브라우저로 Wi-Fi SSID/비밀번호 + 도시명 + UTC 오프셋을 입력받음. 도시명은 Open-Meteo 지오코딩 API로 위경도 자동 변환.
- 설정값(Wi-Fi, 도시, 좌표)은 NVS(Preferences)에 영구 저장 — 재부팅해도 유지, BOOT 버튼 3초 홀드로 초기화 가능.
- BUTTON_2(GPIO14) 짧게 눌러 날씨 즉시 수동 새로고침.
- **화면을 좌(1/4)·우(3/4) 2분할로 재설계**: 왼쪽 1/4(80px)은 장소 + 시:분을 화면 폭에 꽉 차는 큰 글씨로 표시, 오른쪽 3/4은 날씨 정보.
- **날씨별 배경색 자동 전환**: 맑음/부분흐림/흐림/안개/비/눈/뇌우/알수없음 8개 카테고리마다 고유 배경색(RGB565)을 매핑, 오른쪽 패널 전체가 그 색으로 채워짐.
- **날씨 아이콘 추가**: 각 카테고리별로 해/구름/비/눈/번개 등을 직접 그려서(PIL로 절차적 생성, 외부 이미지 라이선스 이슈 없음) 카테고리 배경색에 맞춰 미리 합성한 56×56 아이콘을 표시.
- **한글 UI**: 날씨 상태 설명(맑음/흐림/비/눈 등 15종), 체감·습도·바람·강수 라벨, 8방위 풍향, Wi-Fi 상태, 도시명(서울·부산·인천 등 9개 주요 도시)을 한글 비트맵 단어로 표시. TFT_eSPI 내장 폰트에 없는 한글/℃ 기호를 자체 생성한 1비트 비트맵 폰트(`assets.h`)로 해결.
- 실제 보드에 업로드하여 정상 동작 확인 완료 (2026-07-26, 이후 레이아웃/한글 리디자인은 컴파일 검증 + 좌표 시뮬레이션까지 완료, 실기 재업로드 확인은 사용자 진행 예정).

## 🐞 알려진 이슈

- **City(도시) 입력란은 영문 도시명 권장**: 지오코딩 정확도 때문. 화면에 한글로 표시되는 도시는 사전 등록된 9곳(서울/부산/인천/대구/대전/광주/수원/울산/제주)뿐이며, 그 외 도시는 입력한 영문 그대로 표시됨(임의의 한글 도시명을 실시간 렌더링하는 기능은 아직 없음 — 완전한 한글 조합형 렌더러가 필요해 범위 밖으로 둠).
- 한글/아이콘 비트맵은 `examples/WeatherClock/tools/gen_assets.py`(Python + Pillow, macOS 나눔고딕 폰트 필요)로 생성한 `assets.h`에 고정 저장됨. 새 단어/아이콘이 필요하면 스크립트를 수정 후 재실행 필요(런타임 동적 생성 아님).
- HTTPS 통신 시 `WiFiClientSecure::setInsecure()`로 인증서 검증을 생략함 — 공개 날씨 데이터를 읽기만 하는 개인 프로젝트라 실용적으로 단순화한 것으로, 민감정보 송수신이 없어 문제되지 않지만 참고할 것.
- Open-Meteo API가 `Transfer-Encoding: chunked`로 응답하므로, `HTTPClient`에서 JSON을 파싱할 때는 반드시 `getString()`으로 청크를 해제한 뒤 `deserializeJson()`에 넘겨야 함(`getStream()` 직결 시 "Invalid input" 오류 발생) — 코드에 이미 반영됨, 향후 다른 API 연동 시 동일한 패턴 주의.
